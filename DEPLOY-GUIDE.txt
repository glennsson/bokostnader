--------------------------------------------------------------------------------
1. KORT OPPSUMMERING AV APPEN
--------------------------------------------------------------------------------

Appen er bygget med:
  - React (brukergrensesnitt)
  - Vite (byggeverktøy / dev-server)
  - Express (kun lokalt, for FINN-import under utvikling)
  - Vercel Serverless API (FINN-import i produksjon på nett)

Du har to hovedfaner:
  A) Status quo vs ny bolig  – sammenlign dagens bolig med en du vurderer
  B) Sammenlign flere boformer – f.eks. enebolig vs rekkehus

Ekstra funksjoner:
  - FINN-import (lim inn annonse-URL)
  - Eksport CSV/PDF (fanen «flere boformer»)
  - Kopier delbar lenke (sender med alle tall i URL-en)
  - Adresser + lagring lokalt (nettleser) og valgfritt i skyen (Supabase)
  - Innlogging med e-postlenke – synk på tvers av PC/mobil


--------------------------------------------------------------------------------
1b. SKY-LAGRING (SUPABASE) – VALGFRITT
--------------------------------------------------------------------------------

Uten oppsett lagres data kun i nettleseren (localStorage).
Med Supabase lagres samme JSON også i skyen når du er innlogget.

Steg-for-steg: se filen  supabase/SETUP.md  i prosjektmappen.

Kort versjon:
  1. Opprett gratis prosjekt på https://supabase.com
  2. Kjør SQL fra  supabase/01-kalkulator-grunnlag.sql  m.fl. (SQL Editor, se SETUP.md)
  3. Slå på e-post-innlogging, legg inn redirect-URL (localhost + Vercel)
  4. Kopier .env.example til .env og fyll inn URL + anon key
  5. Lokalt: npm run dev på nytt
  6. Vercel: Settings → Environment Variables (samme to variabler), redeploy

Miljøvariabler (begge må starte med VITE_ for at Vite skal eksponere dem):
  VITE_SUPABASE_URL
  VITE_SUPABASE_ANON_KEY

Data i skyen: én rad per bruker, tabell kalkulator_data, felt payload (JSON).
Kun du ser dine data (Row Level Security).

2. HVORFOR IKKE STREAMLIT?
--------------------------------------------------------------------------------

Streamlit er et Python-rammeverk for enkle webapper. Din app er allerede
ferdig i React. Å flytte til Streamlit ville betydd:

  - Skrive all logikk på nytt i Python
  - Bygge UI på nytt
  - FINN-import måtte lages separat

Anbefaling: Behold React og publiser på Vercel (gratis, enkel, delbar URL).

--------------------------------------------------------------------------------

Filer som ble lagt til/endret for deploy og deling:

  vercel.json

  src/share.js
    - Koder avkrypterer kalkulatordata i URL-parameteren ?d=...
    - Brukes av knappen «Kopier delbar lenke»

  .gitignore
    - Ekskluderer node_modules, dist, .env (skal ikke lastes til GitHub)

  README.md
    - Kort teknisk dokumentasjon på norsk


--------------------------------------------------------------------------------
4. SLIK FUNGERER «KOPIER DELBAR LENKE»
--------------------------------------------------------------------------------

1. Du fyller inn tall i kalkulatoren.
2. Appen pakker data (faner, status quo, ny bolig, boformer) som JSON.
3. JSON konverteres til Base64 og legges i URL: ?d=XXXX
4. Når noen åpner lenken, leser appen parameteren og fyller inn feltene.

Merk:
  - Lenken kan bli lang ved mange boformer (det er normalt).
  - Data ligger i URL-en – ikke send sensitive data du ikke vil dele.


--------------------------------------------------------------------------------
5. KJØRE LOKALT (PÅ DIN PC)
--------------------------------------------------------------------------------

Åpne PowerShell i prosjektmappen og kjør:

  Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
  npm install
  npm run dev

Åpne URL-en Vite viser (f.eks. http://localhost:5173/ eller 5174/).

Hvis du får «port already in use»:
  - Stopp gamle terminaler med Ctrl+C
  - Eller bruk den nye porten Vite foreslår (5174, 5175, …)

Hvis npm feiler med «running scripts is disabled»:
  - Kjør Set-ExecutionPolicy-kommandoen over først (kun denne terminalen).

Git er versjonskontroll. GitHub er lagring i skyen. Vercel henter koden derfra.

--------------------------------------------------------------------------------
7. VERCEL – PUBLISER PÅ NETT (GRATIS)
--------------------------------------------------------------------------------

STEG 7.1 – Opprett konto
  1. Gå til https://vercel.com
  2. Registrer deg (enklest: «Continue with GitHub»)

STEG 7.2 – Importer prosjekt
  1. Klikk «Add New…» → «Project»
  2. Velg GitHub-repoet «bokostnader»
  3. Framework Preset: Vite (ofte auto-detektert)
  4. Build Command: npm run build  (fra vercel.json)
  5. Output Directory: dist         (fra vercel.json)
  6. Klikk Deploy

STEG 7.3 – Vent 1–2 minutter
  Du får en URL, f.eks.:
    https://bokostnader-xxxxx.vercel.app

STEG 7.4 – Automatiske oppdateringer
  Hver gang du kjører «git push», bygger Vercel appen på nytt automatisk.

--------------------------------------------------------------------------------
9. FEILSØKING
--------------------------------------------------------------------------------

Problem: Blank side i nettleser
  - Sjekk F12 → Console for feilmeldinger
  - Sørg for @vitejs/plugin-react er installert (npm install)
  - Hard refresh: Ctrl+F5

Problem: FINN-import virker ikke på Vercel
  - FINN kan blokkere server-henting av enkelte annonser
  - Prøv en annen annonse-URL
  - Sjekk Vercel → Project → Logs → Functions

Problem: EADDRINUSE port 8787
  - En gammel server.js kjører fortsatt – stopp med Ctrl+C eller restart PC

Problem: npm ikke funnet
  - Installer Node LTS: winget install OpenJS.NodeJS.LTS
  - Lukk og åpne terminal på nytt
